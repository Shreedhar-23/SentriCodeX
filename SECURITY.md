# Security Policy

SentriCodeX is a security-focused tool, so we take the security of the
project itself seriously.

## Supported Versions

| Version | Supported |
|---|---|
| v1.x (in development) | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in SentriCodeX itself (not a
finding produced *by* SentriCodeX about your code, but an issue in
SentriCodeX's own code), please report it privately rather than opening a
public GitHub issue. Reporting instructions (email/contact) will be added
once the GitHub repository and publisher profile are created (Phase 9).

## Our Commitment

- SentriCodeX processes all source code **locally** — nothing is uploaded
  to external servers.
- We do not log secrets, API keys, or raw source code contents.
- Dependencies are reviewed periodically for known vulnerabilities.

## Scope

This policy covers the SentriCodeX extension, engine, and rule packs. It
does not cover third-party dependencies (report those upstream).
